# GitHub Publishing Checklist

Before publishing:

1. Do not upload API keys or `.env` files.
2. Do not upload the original transcript DOCX unless you have rights to redistribute it.
3. Prefer keeping transcript-derived chunks private as well.
4. Upload code, README, architecture documentation, and screenshots.
5. Add one screenshot of the Streamlit interface.
6. Add one screenshot of a successful script and evaluation.
7. Do not claim fine-tuning; ScriptMaster does not fine-tune a model.
8. Do not claim the final generator uses raw RAG context; that experiment was intentionally removed after topic-drift testing.

## Suggested repository description

Local AI script-generation system built with Python, Ollama, Qwen3, MiniLM and Streamlit. Analyzes a 100-script corpus, builds a reusable style profile, generates original scripts from one topic input, and evaluates style, relevance and originality.
